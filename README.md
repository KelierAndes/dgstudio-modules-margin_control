# dgstudio-modules-margin_control · 灵猫边控联动模块

DGStudio 的灵猫边控模块：读取**灵猫（BMTR）气压**（0-60 kPa）与**官方边控
会话状态**（DG-Lab 4.0 App 经 Socket V4 上报的 `edgeState` 0-4，控制页
「边控状态」同款语义），按配置跑**闭环状态机**，产出两路强度映射变量
（**刺激器 / 惩罚器**）经核心输入映射表派发给输出设备（郊狼 / 负鼠），
实现自动「**刺激 → 到边 → 冷静 → 恢复**」的边控玩法。

**设备控制只经映射表**：状态机不直接调用任何设备命令（无 zap / fire /
reset 直呼），全部输出由输入映射表行引用 `{stim_strength}` 等变量落地；
默认行「刺激器/惩罚器最大值驱动 A/B 强度」安装即可用，改写行即可换目标
参数（波形、开火、负鼠通道…）或自定义组合。

- 模块开发文档（ModuleContext / 映射表 / 打包约定）见总仓库
  [dgstudio-modules-market/EXTENSIONS.md](https://github.com/KelierAndes/dgstudio-modules-market)。
- 本仓库与 DGStudio 核心仓库（`DG-LAB-X-VRChat-OSC-development`）放同一
  父目录即可直接跑单测（或设 `DGSTUDIO_CORE`）。

## 使用

1. DGStudio「模块」页 → 在线列表找到「灵猫边控联动」→ 安装并启动
   （无第三方依赖）。
2. 连接灵猫（蓝牙直连或 Socket V4）与输出设备；先用灵猫卡片上的
   「**气压清零**」校准静息 0 点，再按佩戴后的静息气压与刺激手感调整
   「边缘阈值 / 恢复阈值」。
3. 联动页「灵猫边控联动」卡片按需调整玩法参数与映射表；卡片顶部的
   「实时数据」会显示六个变量的实时值。

安装即可用的默认行为（`sensor` 模式）：刺激期从 0 缓升到「刺激强度」，
平滑气压升到「边缘阈值」判定到边，以「惩罚器强度」短促输出后撤除刺激
进入冷静；冷静满「冷静最短时长」且气压回落到「恢复阈值」以下才恢复刺激。
**循环达「循环上限」后进入释放期**（以助力强度经刺激器变量持续输出），
释放满「释放时长」循环计数清零、重新开始刺激。

## 三种边控模式

| 模式 | 依据 | 行为 |
|---|---|---|
| `sensor`（默认） | 灵猫气压 | 气压闭环：到边→冷静（惩罚窗口）→恢复，循环计数；达循环上限→释放（助力输出），释放期满清零重开 |
| `app` | 官方边控会话 | 跟随 App 边控状态：1 刺激→刺激器输出；2/3 冷静计时/判定→撤除（惩罚窗口同）；4 允许高潮→助力输出；0 停止→待机。释放只由会话决定，循环上限不介入 |
| `off` | — | 不闭环、不动设备，仅提供映射变量供自定义映射表使用 |

官方边控状态（核心 `ui/live.EDGE_STATES`）：`0 停止 / 1 刺激 / 2 冷静计时 /
3 冷静判定 / 4 允许高潮`。`app` 模式需要 DG-Lab 4.0 App 的边控玩法会话在跑
（Socket V4 连接）；蓝牙直连的灵猫没有该状态，请用 `sensor` 模式。

## 映射变量（6 个）

| 变量 | 说明 |
|---|---|
| `{pressure}` | 平滑后气压 (kPa) |
| `{edge}` | 官方边控状态 0-4（无会话为 0） |
| `{stim_strength}` | **刺激器强度**（刺激/助力共用一个数据项）：刺激期按爬升时长趋向刺激强度，冷静期维持冷静强度，释放期输出助力强度，其余 0 |
| `{punish_strength}` | **惩罚器强度**：到边进冷静后的惩罚输出，惩罚时长内非零 |
| `{on_edge}` | 到边标志：平滑气压 ≥ 边缘阈值时为 1 |
| `{cycles}` | **边控循环**：当前轮「到边→冷静」计数；释放完成后清零重新计 |

输入映射表留空即用默认行：

```
in_strength_a = max({stim_strength}, {punish_strength})
in_strength_b = max({stim_strength}, {punish_strength})
```

两路取最大值——刺激期与释放期 = 刺激器变量（刺激/助力强度）、到边惩罚窗口 = 惩罚器强度，
其余时刻 0。表中添加任意行后完全由配置决定，例如：

| 想要 | 映射行 |
|---|---|
| 只驱动 A 通道 | `in_strength_a = max({stim_strength}, {punish_strength})`，B 行删掉 |
| 到边瞬间来一下更强惩罚 | 默认行已是此行为（惩罚器强度 > 刺激/助力强度时窗口内取惩罚值） |
| 释放期定时开火助力 | `in_fire = {stim_strength}`（正值开火保持，归 0 停止并恢复） |
| 气压直接驱动强度 | `in_strength_a = {pressure} * 3` |
| 用到边标志触发急停 | `in_emergency = {on_edge}`（慎用） |

表达式支持四则运算与 `abs/min/max/round`（不支持比较运算符）。

## 安全设计

- **全程映射表通道**：状态机零直接设备命令；惩罚、刺激全部是映射变量，
  删掉映射行即彻底断开对应输出。
- **失联判停**：超过「气压失联判停」秒数没有新的气压读数，闭环归零待机
  （每 30s 至多提示一条日志），灵猫恢复后重新进入刺激期。
- **暂停按键**：负鼠物理按键绑定「边控闭环 暂停/恢复」，暂停即两路输出
  清零（经映射表派发），可随时掐断闭环；「灵猫气压清零」按键同控制页按钮。
- **停止归零经映射表**：停止/卸载模块时把两路输出清零重新求值——默认行
  求值 0 即派发归零；映射表没有强度行则不动设备（不会误清手动强度）。

## 配置项（联动页可改，即存即生效）

| 配置 | 默认 | 说明 |
|---|---|---|
| 边控模式 | `sensor` | `sensor` / `app` / `off` |
| 边缘阈值 (kPa) | 40 | 升到该值判定到边（先用「气压清零」校准 0 点） |
| 恢复阈值 (kPa) | 20 | 冷静期回落到该值以下才恢复（与边缘阈值构成回差防抖） |
| 冷静最短时长 (秒) | 10 | 到边后至少冷静该时长 |
| 刺激强度 | 60 | 刺激期目标强度 0-200（经 `{stim_strength}` 落地） |
| 助力强度 | 80 | 释放期输出强度 0-200（与刺激强度共用映射变量 `{stim_strength}`） |
| 冷静期强度 | 0 | 冷静期维持强度（0=完全撤除） |
| 刺激爬升时长 (秒) | 3 | 进入刺激期从 0 缓升到目标，0=立即 |
| 惩罚器强度 | 100 | 到边瞬间短促输出的强度 0-200（经 `{punish_strength}`，0=关闭） |
| 惩罚时长 (秒) | 1 | 惩罚输出持续时长，0=关闭惩罚 |
| 释放时长 (秒) | 15 | 释放期满循环计数清零重新刺激；0=保持释放直到暂停/失联 |
| **循环上限 (轮)** | 0 | **边控循环达该轮数后允许释放**（进入释放期，输出助力强度）；0=不限制（仅 sensor 模式） |
| 气压平滑 | 0.5 | 指数平滑系数，越大越稳（0 关闭） |
| 气压失联判停 (秒) | 5 | 无新读数超此时长即闭环归零待机 |
| 灵猫设备 (slot_id) | 空 | 留空用第一台灵猫 |
| 输入映射表 | 空 | 行 `{param, expr}`；留空用默认行（设备控制唯一通道） |

映射表与闭环参数支持**热生效**（联动页「保存设置」即重载）；绑定设备
（slot_id）改动同样热读，无需重开模块。映射派发的目标设备由核心按家族
解析（各家族第一台输出设备），无需配置。

## 联动原理

```
灵猫 (BMTR) 气压 kPa / 官方边控状态 0-4   ← 核心 slot.pressure / slot.edge_state
        │  每 0.1s 一拍：指数平滑 + 失联判定
        ▼
EdgeGuard 闭环状态机（sensor 气压闭环 / app 跟随会话 / 循环上限释放）
   │ 两路强度输出：刺激器 / 惩罚器（0-200）
   ▼
六个映射变量 ──► 模块映射引擎 ──► 核心输入映射表 ──► 强度 / 波形 / 开火…
                                        ▲ 唯一设备控制通道
```

- 边控变量与核心输出参数共用同一表达式空间，`{stim_strength}` 可与
  `{Strength}`、`{Limit}`、`{Pressure}` 等自由组合运算。
- 模块不持有任何设备命令直呼路径：`zap` / `fire` / `reset_strength` /
  `emergency_stop` 等只能经映射行目标参数（`in_*`）间接触达。

## 开发

```
dgstudio-modules-margin_control/
├── modules/margin_control/
│   ├── plugin.py      META（参数/配置/按键动作声明）+ 模块类
│   ├── bridge.py      EdgeGuard 闭环状态机 + MarginBridge 节拍与映射派发
│   └── requirements.txt  纯标准库，无第三方依赖
└── tests/             单测（状态机纯逻辑 + 桥接器假件 + 插件契约）
```

在本仓库根目录运行：

```
python -m unittest discover -s tests
```
