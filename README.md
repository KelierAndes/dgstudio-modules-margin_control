# dgstudio-modules-margin_control · 灵猫边控联动模块

DGStudio 的灵猫边控模块：读取**灵猫（BMTR）气压**（0-60 kPa）与**官方边控
会话状态**（DG-Lab 4.0 App 经 Socket V4 上报的 `edgeState` 0-4，控制页
「边控状态」同款语义），按配置跑**闭环状态机**，把目标强度经核心输入映射
表派发给输出设备（郊狼 / 负鼠），实现自动「**刺激 → 到边 → 冷静 → 恢复**」
的边控玩法。

- 模块开发文档（ModuleContext / 映射表 / 打包约定）见总仓库
  [dgstudio-modules-market/EXTENSIONS.md](https://github.com/KelierAndes/dgstudio-modules-market)。
- 本仓库与 DGStudio 核心仓库（`DG-LAB-X-VRChat-OSC-development`）放同一
  父目录即可直接跑单测（或设 `DGSTUDIO_CORE`）。

## 使用

1. DGStudio「模块」页 → 在线列表找到「灵猫边控联动」→ 安装并启动
   （无第三方依赖）。
2. 连接灵猫（蓝牙直连或 Socket V4）与输出设备；先用灵猫卡片上的
   「**气压清零**」校准静息 0 点，再按佩戴后的静息气压与刺激手感调整
   「边缘阈值 / 恢复阈值」。
3. 联动页「灵猫边控联动」卡片按需调整玩法参数与映射表；卡片顶部的
   「实时数据」会显示七个变量的实时值。

安装即可用的默认行为（`sensor` 模式）：刺激期从 0 缓升到「刺激期强度」，
平滑气压升到「边缘阈值」判定到边，立即撤除刺激进入冷静；冷静满
「冷静最短时长」且气压回落到「恢复阈值」以下才恢复刺激，往复循环。

## 三种边控模式

| 模式 | 依据 | 行为 |
|---|---|---|
| `sensor`（默认） | 灵猫气压 | 气压闭环：到边阈值→冷静（可选拿双通道惩罚脉冲），冷静期满且气压回落→恢复刺激，循环计数 |
| `app` | 官方边控会话 | 跟随 App 边控状态：1 刺激→维持刺激强度；2/3 冷静计时/判定→撤除；4 允许高潮→释放强度（可选定时开火助飞）；0 停止→待机 |
| `off` | — | 不闭环、不动设备，仅提供映射变量供自定义映射表使用 |

官方边控状态（核心 `ui/live.EDGE_STATES`）：`0 停止 / 1 刺激 / 2 冷静计时 /
3 冷静判定 / 4 允许高潮`。`app` 模式需要 DG-Lab 4.0 App 的边控玩法会话在跑
（Socket V4 连接）；蓝牙直连的灵猫没有该状态，请用 `sensor` 模式。

## 映射变量（7 个）

| 变量 | 说明 |
|---|---|
| `{pressure}` | 平滑后气压 (kPa) |
| `{pressure_pct}` | 气压百分比 0-100（60 kPa 满量程，与控制页曲线一致） |
| `{edge}` | 官方边控状态 0-4（无会话为 0） |
| `{phase}` | 闭环阶段：0 待机 / 1 刺激 / 2 冷静 / 3 释放 |
| `{drive}` | 状态机当前目标强度 0-200（默认行直接驱动 A/B 强度） |
| `{on_edge}` | 平滑气压 ≥ 边缘阈值时为 1 |
| `{cycles}` | 本次运行累计「到边→冷静」次数 |

输入映射表留空即用默认行（`in_strength_a = {drive}`、`in_strength_b =
{drive}`）；表中添加任意行后完全由配置决定——可只驱动单通道、把气压映射
到波形选择、用 `{on_edge}` 触发开火（`in_fire`）等。表达式里也可混用核心
输出参数（如 `{Pressure}`、`{BMTR.Pressure}`）。

## 安全设计

- **失联判停**：超过「气压失联判停」秒数没有新的气压读数，闭环归零待机
  （每 30s 至多提示一条日志），灵猫恢复后重新进入刺激期。
- **暂停按键**：负鼠物理按键绑定「边控闭环 暂停/恢复」，暂停即目标强度
  归零，可随时掐断闭环；「灵猫气压清零」按键同控制页按钮。
- **停止归零**：停止/卸载模块时，归零本模块实际派发过的强度通道（未派发
  过不动设备，避免误清手动强度）。急停请直接用核心「急停」（`in_emergency`
  也可映射）。

## 配置项（联动页可改，即存即生效）

| 配置 | 默认 | 说明 |
|---|---|---|
| 边控模式 | `sensor` | `sensor` / `app` / `off` |
| 边缘阈值 (kPa) | 40 | 升到该值判定到边（先用「气压清零」校准 0 点） |
| 恢复阈值 (kPa) | 20 | 冷静期回落到该值以下才恢复（与边缘阈值构成回差防抖） |
| 冷静最短时长 (秒) | 10 | 到边后至少冷静该时长 |
| 刺激期强度 | 60 | 刺激期目标强度 0-200（波形/上限请在控制页调好） |
| 冷静期强度 | 0 | 冷静期维持强度（0=完全撤除） |
| 释放期强度 | 0 | App 模式「允许高潮」时维持强度 |
| 刺激爬升时长 (秒) | 3 | 进入刺激期从 0 缓升到目标，0=立即 |
| 到边惩罚脉冲 (秒) | 0 | 到边瞬间对目标设备双通道各来一次 N 秒瞬时脉冲，0=关闭 |
| 释放开火时长 (秒) | 0 | 进入「允许高潮」时定时开火 N 秒，0=关闭（app 模式） |
| 气压平滑 | 0.5 | 指数平滑系数，越大越稳（0 关闭） |
| 气压失联判停 (秒) | 5 | 无新读数超此时长即闭环归零待机 |
| 灵猫设备 (slot_id) | 空 | 留空用第一台灵猫 |
| 目标输出设备 (slot_id) | 空 | 惩罚脉冲/释放开火/停止归零的落点；留空自动选择 |
| 输入映射表 | 空 | 行 `{param, expr}`；留空用默认行 |

映射表与闭环参数支持**热生效**（联动页「保存设置」即重载）；绑定设备
（slot_id）改动同样热读，无需重开模块。

## 联动原理

```
灵猫 (BMTR) 气压 kPa / 官方边控状态 0-4   ← 核心 slot.pressure / slot.edge_state
        │  每 0.1s 一拍：指数平滑 + 失联判定
        ▼
EdgeGuard 闭环状态机（sensor 气压闭环 / app 跟随会话）
   │ 阶段 phase · 目标强度 drive · 到边动作（惩罚脉冲 / 释放开火）
   ▼
七个映射变量 ──► 模块映射引擎 ──► 核心输入映射表 ──► 强度 / 波形 / 开火…
```

- 到边动作（`deny_zap_s` / `release_fire_s`）经引擎命令层落到「目标输出
  设备」，与映射表派发互不干扰。
- 边控变量与核心输出参数共用同一表达式空间，`{pressure}` 可与
  `{Strength}`、`{Limit}` 等自由组合运算。

## 开发

```
dgstudio-modules-margin_control/
├── modules/margin_control/
│   ├── plugin.py      META（参数/配置/按键动作声明）+ 模块类
│   ├── bridge.py      EdgeGuard 闭环状态机 + MarginBridge 节拍与派发
│   └── requirements.txt  纯标准库，无第三方依赖
└── tests/             单测（状态机纯逻辑 + 桥接器假件 + 插件契约）
```

在本仓库根目录运行：

```
python -m unittest discover -s tests
```
