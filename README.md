# dgstudio-modules-margin_control · 灵猫边控联动模块

DGStudio 的灵猫边控模块：读取**灵猫（BMTR）气压**（0-60 kPa）与**官方边控
会话状态**（DG-Lab 4.0 App 经 Socket V4 上报的 `edgeState` 0-4），采用
**事件流驱动**的变量处理架构——状态机只产出**事实**（相位、循环计数、
红线/蓝线、到边/恢复/释放/会话状态事件），全部行为选择由配置中的
**事件流规则**构造，经核心输入映射表派发给输出设备（郊狼 / 负鼠），实现
自动「**刺激 → 到边 → 冷静 → 恢复**」的边控玩法。

**设备控制只经映射表**：状态机与事件流都不直接调用任何设备命令（无
zap / fire / reset 直呼），全部输出由输入映射表行引用 `{stim_strength}`
等变量落地；默认行「刺激器/惩罚器最大值驱动 A/B 强度」安装即可用。

- 模块开发文档（ModuleContext / 映射表 / 打包约定）见总仓库
  [dgstudio-modules-market/EXTENSIONS.md](https://github.com/KelierAndes/dgstudio-modules-market)。
- 本仓库与 DGStudio 核心仓库（`DG-LAB-X-VRChat-OSC-development`）放同一
  父目录即可直接跑单测（或设 `DGSTUDIO_CORE`）。

## 使用

1. DGStudio「模块」页 → 在线列表找到「灵猫边控联动」→ 安装并启动
   （无第三方依赖；默认事件流自动写入配置文件）。
2. 连接灵猫（蓝牙直连或 Socket V4）与输出设备；先用灵猫卡片上的
   「**气压清零**」校准静息 0 点，再按佩戴后的静息气压调整
   「边缘气压阈值 / 恢复气压阈值」（默认 17.0 / 15.0 kPa，同官方）。
3. 联动页「灵猫边控联动」卡片按需调整事件流、判定参数与映射表；卡片
   顶部的「实时数据」会显示变量表（事实 / 输出 / 设置镜像）的实时值。

默认行为（默认事件流构造）：刺激期从 0 缓升到「刺激强度」，气压高于红线
（或短窗口快速上升）判到边，惩罚器输出 100 维持 1 秒后自动归零，撤除刺激
进入冷静；冷静满「最小冷静时间」且气压持续低于蓝线才恢复刺激；**边控
5 轮后进入释放期**（助力强度输出），释放满「释放时长」清零计数重新开始。
阈值自适应：每次边控后红线按设置百分比下降（蓝线按比例跟随）、久不到边
红线缓降、冷静过久蓝线回升（恢复变容易）。

## 事件流（行为选择在此构造）

配置项「事件流」是规则列表，按声明顺序执行；**删改规则即改变行为**，
取代旧版的模式 / 惩罚 / 释放条件 / 自适应开关等设置项。

规则 schema：

```json
{"on": "edge",                      // 触发事件
 "where": {"cycles": {"min": 5}},   // 可选：变量条件（min/max 含边界，值可为表达式）
 "set": {"release_req": 1},         // 变量赋值（数字或表达式，按序生效）
 "revert": {"punish_strength": 0},  // 可选：after_s 秒后回滚
 "after_s": 1.0}
```

触发事件：`tick`（每拍 0.1s）、`edge`（判到边）、`recovered`（恢复刺激）、
`release`（进入释放期）、`stim`（进入/回到刺激期）、`app_0`…`app_4`
（官方边控会话状态变化）。表达式经核心安全求值（四则运算 +
`abs/min/max/round`，不支持比较运算符），未定义变量按 0 处理。

默认事件流（宿主装载时写入配置文件，可随时改回）：

| 规则 | 构造的行为（旧设置项） |
|---|---|
| `app_1/app_2+app_3/app_4/app_0 → 相位` | 官方会话接线（旧「边控模式」选择；与气压判定共用状态流，二者皆可驱动） |
| `edge → punish_strength=100，1s 后回滚 0` | 到边惩罚（旧「惩罚器强度/时长」） |
| `edge → red 按设置 % 下降；blue 按比例跟随` | 边控后红线自适应（旧「自适应开关」+ 数值） |
| `tick（刺激期超时）→ red 缓降` | 久不到边红线缓降 |
| `tick（冷静期超时）→ blue 缓升` | 久未恢复蓝线回升（恢复变容易） |
| `tick（按相位）→ stim_strength` | 刺激期爬升 / 冷静期维持 / 释放期助力 / 待机归零 |
| `recovered（cycles ≥ 5）→ release_req=1` | 边控 5 轮后允许释放（旧「循环上限」；删除该行即不限次数） |

常用自定义行示例：

```json
{"on": "tick", "where": {"session_time": {"min": 1800}, "phase": {"max": 2}},
 "set": {"release_req": 1}}                    // 会话 30 分钟后允许释放
{"on": "release", "set": {"punish_strength": "{assist_setting}"},
 "revert": {"punish_strength": 0}, "after_s": 5.0}   // 释放瞬间来一段强输出
```

清空事件流 = 关闭全部行为构造（安全开关；状态机事实照常产出，但无变量
被赋值，映射表无可驱动之量）。

## 判定条件（取值类设置项）

- **红线**（边缘气压阈值，默认 17.0 kPa）：刺激期气压高于红线判「即将
  高潮」；可要求**连续 N 秒高于红线**（持续判定防抖，默认 0=立即）。
- **气压跳变**：观测窗口（默认 2 秒）内上升速率达阈值（kPa/s）也判即将
  高潮——对应官方「气压短时间上升差值」，0 = 关闭。
- **蓝线**（恢复气压阈值，默认 15.0 kPa）：冷静期满「最小冷静时间」
  （默认 10 秒）且气压低于蓝线判恢复；可要求**连续 N 秒低于蓝线**
  （默认 5 秒，官方同款）。
- **漏气补偿**（kPa）：叠加到气压读数上的固定偏移（官方默认 3）。
- **释放时长**（秒）：释放期满清零计数重新刺激；0 = 保持释放。

自适应**数值**仍是设置项（边控后红线下降 %、红线下降速度 %/s、缓降/
回升等待秒、蓝线跟随 %），默认事件流经镜像变量引用它们；删除对应规则
即关闭该自适应行为。

## 变量表（24 个，映射表与事件流共用）

| 类别 | 变量 |
|---|---|
| 事实（状态机产出） | `{pressure}` 平滑+漏气补偿气压、`{edge}` 官方状态 0-4、`{phase}` 相位 0-3、`{phase_time}` 相位时长、`{session_time}` 会话时长、`{red}` / `{blue}` 当前红线/蓝线、`{cycles}` 边控循环、`{on_edge}` 到边标志、`{on_release}` 释放标志 |
| 输出（默认事件流构造） | `{stim_strength}` 刺激器强度（刺激期爬升/冷静期冷静/释放期助力）、`{punish_strength}` 惩罚器强度（到边惩罚窗口） |
| 设置镜像（随设置热更新） | `{stim_setting}` / `{cool_setting}` / `{assist_setting}` / `{ramp_s}` / `{edge_threshold}` / `{recovery_threshold}` / `{adapt_drop_pct}` / `{adapt_drop_rate}` / `{adapt_drop_delay_s}` / `{adapt_blue_follow}` / `{adapt_blue_rise_rate}` / `{adapt_blue_delay_s}` |

输入映射表留空即用默认行：

```
in_strength_a = max({stim_strength}, {punish_strength})
in_strength_b = max({stim_strength}, {punish_strength})
```

自定义行示例：只驱动 A 通道（删 B 行）、释放期开火助力
（`in_fire = {on_release}`）、气压直接驱动强度（`in_strength_a =
{pressure} * 3`）、用到边标志触发急停（`in_emergency = {on_edge}`，慎用）。

## 安全设计

- **全程映射表通道**：状态机与事件流零直接设备命令；删掉映射行即彻底
  断开对应输出，清空事件流即关闭全部行为构造。
- **失联判停**：超过「气压失联判停」秒数没有新的气压读数，闭环归零待机
  （每 30s 至多提示一条日志）；从未有过读数（纯官方会话）则不强制。
- **暂停按键**：负鼠物理按键绑定「边控闭环 暂停/恢复」，暂停即相位归位、
  输出经映射表归零；「灵猫气压清零」按键同控制页按钮。
- **停止归零经映射表**：停止/卸载模块时把输出变量清零重新求值——默认行
  求值 0 即派发归零；映射表没有强度行则不动设备（不会误清手动强度）。
- **红线/蓝线安全间隙**：无论事件流如何改写，蓝线恒被钳制在红线以下
  （至少低 0.5 kPa），红线不低于 1 kPa。

## 联动原理

```
灵猫 (BMTR) 气压 kPa / 官方边控状态 0-4   ← 核心 slot.pressure / slot.edge_state
        │  每 0.1s 一拍：指数平滑 + 漏气补偿 + 失联判定
        ▼
EdgeGuard 状态机（只产出事实）
   相位 · 循环计数 · 红线/蓝线 · 事件：edge / recovered / release / stim / app_N
        ▼
事件流规则（配置 events，按序执行：where 条件 → set 赋值 → 定时回滚）
   行为选择：官方会话接线 · 惩罚 · 阈值自适应 · 释放条件 · 相位→刺激器输出
        ▼
变量表（24 变量）──► 模块映射引擎 ──► 核心输入映射表 ──► 强度 / 波形 / 开火…
                                          ▲ 唯一设备控制通道
```

- 事件流规则可引用核心输出参数（`{Strength}`、`{Limit}`、`{Pressure}`…）
  与变量表自由组合运算。
- 模块不持有任何设备命令直呼路径：`zap` / `fire` / `reset_strength` /
  `emergency_stop` 等只能经映射行目标参数（`in_*`）间接触达。

## 开发

```
dgstudio-modules-margin_control/
├── modules/margin_control/
│   ├── plugin.py      META（变量/配置/默认事件流声明）+ 模块类
│   ├── bridge.py      EdgeGuard 事实状态机 + EventStream 规则引擎 + MarginBridge
│   └── requirements.txt  纯标准库，无第三方依赖
└── tests/             单测（状态机 + 规则引擎 + 默认事件流 + 插件契约）
```

在本仓库根目录运行：

```
python -m unittest discover -s tests
```
