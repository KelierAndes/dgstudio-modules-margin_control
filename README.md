# 灵猫边控联动（DGStudio 模块）

DGStudio 的灵猫边控模块：**纯数值推送**的双向映射管道（核心 ⇄ 模块），
模块**不做任何设备管理**——实现自动「**刺激 → 到边 → 冷静 → 恢复**」
边控玩法，判定条件与阈值自适应对标 DG-Lab 官方边控玩法设置页，全部数值
经两张映射表流动。

- DGStudio 核心仓库：
  [DG-Lab-Studio](https://github.com/KelierAndes/DG-Lab-Studio)
- 模块市场仓库：
  [dgstudio-modules-market](https://github.com/KelierAndes/dgstudio-modules-market)

* **核心 → 模块（输出映射表）**：`BMTR.Pressure → pressure`、
  `BMTR.EdgeState → edge`，从核心输出信号空间读入灵猫气压（0-60 kPa）与
  官方边控会话状态；换绑其它灵猫 = 改输出表行（如 `BMTR.2.Pressure`）；
* **模块 → 核心（输入映射表 / 推送链）**：发布 `stim_strength` /
  `punish_strength` 等命名数值；推送链（配置项 `events`，行
  `{actions: [{dir: "in", param, var}]}`）声明「核心参数 ← 变量」的连续
  推送，如 `in_strength_a ← punish`、`in_ovc_strength_a ← stim`——目标
  设备/通道完全由核心输入参数 id 决定（`in_*` 郊狼、`in_ovc_*` 负鼠），
  模块只推数、不选设备。`temps`（行 `{name, expr}`）定义派生变量
  （如 `punish ← {punish_strength}`），每拍求值供推送链引用。
  优先级：显式 `mappings` 行 > 推送链 > 默认行
  （`in_strength_a/b ← max(刺激, 惩罚)`）。

## 功能

默认行为（`sensor` 模式）：刺激期从 0 缓升到「刺激强度」，气压高于红线
（或短窗口快速上升）判到边，以「惩罚器强度」短促输出后撤除刺激进入冷静；
冷静满「最小冷静时间」且气压持续低于蓝线才恢复刺激。**边控 5 次（或会话
时长达限）后进入释放期**（助力强度输出），释放满「释放时长」循环计数清零、
重新开始。阈值随玩法自适应：每次边控后红线下降、久不到边红线缓降、
蓝线按比例跟随；冷静过久蓝线回升（恢复变容易）。

### 三种边控模式

| 模式 | 依据 | 行为 |
|---|---|---|
| `sensor`（默认） | 灵猫气压 | 气压闭环（判定条件见下）；边控次数或会话时长达限 → 释放（助力输出），释放期满清零重开 |
| `app` | 官方边控会话 | 跟随 App 边控状态：1 刺激→刺激器输出；2/3 冷静计时/判定→撤除（惩罚窗口同）；4 允许高潮→助力输出；0 停止→待机。次数/时长释放不介入 |
| `off` | — | 不闭环、不动设备，仅提供映射变量供自定义映射表使用 |

官方边控状态（核心 `ui/live.EDGE_STATES`）：`0 停止 / 1 刺激 / 2 冷静计时 /
3 冷静判定 / 4 允许高潮`。`app` 模式需要 DG-Lab 4.0 App 的边控玩法会话在跑
（Socket V4 连接）；蓝牙直连的灵猫没有该状态，请用 `sensor` 模式。

### 判定条件（对标官方「判定条件」页）

- **红线**（边缘气压阈值，默认 17.0 kPa）：刺激期气压高于红线判「即将
  高潮」；可要求**连续 N 秒高于红线**（持续判定防抖）。
- **气压跳变**：观测窗口（默认 2 秒）内上升速率达阈值（kPa/s）也判即将
  高潮——对应官方「气压短时间上升差值」，0 = 关闭。
- **蓝线**（恢复气压阈值，默认 15.0 kPa）：冷静期满「最小冷静时间」
  （默认 10 秒）且气压低于蓝线判恢复；可要求**连续 N 秒低于蓝线**
  （默认 5 秒，官方同款）。
- **阈值自适应**（对应官方「阈值自适应调整」）：
  - 刺激阶段：每次成功边控后红线按百分比立即下降；超过等待时长仍未到边，
    红线按速率（%/s）**线性**缓慢下降（按配置基线计算，不复利衰减）；
    蓝线按「跟随百分比」同步下探；
  - 冷静阶段：超过等待时长仍未恢复，蓝线按速率（%/s）上升——恢复变容易；
  - **红线下限**：红线恒不低于「恢复阈值 + 0.5 kPa」——自适应无论累计
    多少，到边判定都不会跌破设定阈值区间（红线不会无声衰减到低气压区）；
  - 红线/蓝线间恒保持 0.5 kPa 安全间隙（蓝线不会越过红线）。
- **漏气补偿**：叠加到气压读数上的固定偏移（腔体漏气读数偏低时调大；
  官方默认 3 kPa）。

### 释放触发（满足其一进释放期）

| 条件 | 配置 | 官方对应 |
|---|---|---|
| 边控次数 | `边控次数释放 (轮)`，默认 5，0=不限 | 「指定边控次数后，允许高潮释放（固定模式）」 |
| 持续时长 | `持续时长释放 (秒)`，默认 0=关闭 | 「游戏进行指定时长后，允许高潮释放」 |
| App 会话 | 状态 4（仅 app 模式） | 「允许高潮」 |

释放期以「助力强度」经刺激器变量持续输出；「释放时长」满后循环计数清零、
重新开始刺激（0 = 保持释放直到暂停/失联）。

### 安全设计

- **全程映射表通道**：状态机零直接设备命令；惩罚、刺激全部是映射变量，
  删掉映射行即彻底断开对应输出。
- **失联判停**：有效气压须高于 0.05 kPa 且读数在「气压失联判停」秒数
  内有变化，否则闭环归零待机（每 30s 至多提示一条日志）——静息清零后
  0 附近抖动不再引发待机/刺激抖动。
- **暂停按键**：负鼠物理按键绑定「边控闭环 暂停/恢复」，暂停即两路输出
  清零（经映射表派发），可随时掐断闭环；「灵猫气压清零」按键同控制页按钮。
- **停止归零经映射表**：停止/卸载模块时把两路输出清零重新求值——默认行
  求值 0 即派发归零；映射表没有强度行则不动设备（不会误清手动强度）。
- **红线/蓝线安全间隙**：自适应后蓝线恒不越过红线（至少低 0.5 kPa），
  红线恒不低于「恢复阈值 + 0.5 kPa」；缓降按配置基线线性计算，
  自适应累计只增不回跳（重开模块复位）。
- **读数有效性**：有效气压须高于 0.05 kPa 且在 `sensor_timeout_s` 内
  有变化——设备离线（输出表恒 0.0）、「气压清零」后静息、读数冻结均
  判定无效，闭环归零待机，不会在无反馈时盲推强度。
- **零内置兜底行**：模块不携带任何内置映射行——输入/输出映射表与推送
  链只来自配置文件；配置链为空 = 不读数据、不推数值（安全待机）。
- **派发路由交还核心**：模块只推数（输入映射行 = 核心输入参数 id），
  设备定位按核心输入路由语义（各类型首台，跳过灵猫）；驱动负鼠 = 在
  「输入映射表」写 `in_ovc_strength_a/b` 行。

## 安装

DGStudio「模块」页 → 在线列表找到「灵猫边控联动」→ 安装并启动
（无第三方依赖）。

## 配置与使用

1. 连接灵猫（蓝牙直连或 Socket V4）与输出设备；先用灵猫卡片上的
   「**气压清零**」校准静息 0 点，再按佩戴后的静息气压调整
   「边缘气压阈值 / 恢复气压阈值」（默认 17.0 / 15.0 kPa，同官方）。
   多台灵猫时在联动页「输出映射表」把行改指向目标（如 `BMTR.2.Pressure`）；
   分设备驱动（如 郊狼A ← 惩罚、负鼠A ← 刺激）在联动页「输入映射表」或
   「推送链」写 `param ← var` 行（`in_strength_a ← {punish_strength}`、
   `in_ovc_strength_a ← {stim_strength}`）。
2. 联动页「灵猫边控联动」卡片按需调整玩法参数与映射表；卡片顶部的
   「实时数据」会显示七个变量的实时值。

### 映射变量（7 个）

| 变量 | 说明 |
|---|---|
| `{pressure}` | 平滑 + 漏气补偿后气压 (kPa) |
| `{edge}` | 官方边控状态 0-4（无会话为 0） |
| `{stim_strength}` | **刺激器强度**（刺激/助力共用一个数据项）：刺激期按爬升时长趋向刺激强度，冷静期维持冷静强度，释放期输出助力强度，其余 0 |
| `{punish_strength}` | **惩罚器强度**：到边进冷静后的惩罚输出，惩罚时长内非零 |
| `{on_edge}` | 到边标志：气压 ≥ 当前红线（自适应后）时为 1 |
| `{on_release}` | **释放标志**：释放期（允许高潮，助力输出）为 1，其余 0 |
| `{cycles}` | **边控循环**：当前轮「到边→冷静」计数；释放完成后清零重新计 |

输入映射表留空即用默认行：

```
in_strength_a = max({stim_strength}, {punish_strength})
in_strength_b = max({stim_strength}, {punish_strength})
```

两路取最大值——刺激期与释放期 = 刺激器变量（刺激/助力强度）、到边惩罚
窗口 = 惩罚器强度，其余时刻 0。表中添加任意行后完全由配置决定，例如：

| 想要 | 映射行 |
|---|---|
| 只驱动 A 通道 | `in_strength_a = max({stim_strength}, {punish_strength})`，B 行删掉 |
| 到边瞬间来一下更强惩罚 | 默认行已是此行为（惩罚器强度 > 刺激/助力强度时窗口内取惩罚值） |
| 释放期定时开火助力 | `in_fire = {on_release}` 或 `in_fire = {stim_strength}`（正值开火保持，归 0 停止并恢复） |
| 气压直接驱动强度 | `in_strength_a = {pressure} * 3` |
| 用到边标志触发急停 | `in_emergency = {on_edge}`（慎用） |

表达式支持四则运算与 `abs/min/max/round`（不支持比较运算符）。

### 配置项（联动页可改，即存即生效）

分组对齐官方设置页：基础 / 判定条件 / 释放 / 强度 / 阈值自适应 / 映射表。

| 配置 | 默认 | 说明 |
|---|---|---|
| **基础** | | |
| 边控模式 | `sensor` | `sensor` / `app` / `off` |
| 气压平滑 | 0.5 | 指数平滑系数，越大越稳（0 关闭） |
| 气压失联判停 (秒) | 5 | 无新读数超此时长即闭环归零待机 |
| **判定条件** | | |
| 边缘气压阈值 (kPa) | 17.0 | 红线：高于该值判即将高潮（参与自适应） |
| 恢复气压阈值 (kPa) | 15.0 | 蓝线：低于该值判恢复/冷静 |
| 持续高于红线判定 (秒) | 0 | 连续 N 秒高于红线才判到边，0=立即 |
| 跳变阈值 (kPa/s) | 0 | 短窗口快速上升达该速率也判到边（官方「气压短时间上升差值」），0=关闭 |
| 跳变观测窗口 (秒) | 2 | 计算上升速率的时间窗口 |
| 最小冷静时间 (秒) | 10 | 到边后至少冷静该时长 |
| 持续低于蓝线判定 (秒) | 5 | 连续 N 秒低于蓝线才判恢复，0=立即 |
| **释放** | | |
| 边控次数释放 (轮) | 5 | 指定边控次数后允许高潮释放（官方「固定模式」），0=不限 |
| 持续时长释放 (秒) | 0 | 会话进行该时长后允许释放，0=关闭 |
| 释放时长 (秒) | 15 | 释放期满清零计数重新刺激；0=保持释放 |
| **强度** | | |
| 刺激强度 | 60 | 刺激期目标强度（经 `{stim_strength}` 落地） |
| 冷静期强度 | 0 | 冷静期维持强度（0=完全撤除） |
| 助力强度 | 80 | 释放期输出强度（与刺激强度共用 `{stim_strength}`） |
| 刺激爬升时长 (秒) | 3 | 进入刺激期从 0 缓升到目标，0=立即 |
| 惩罚器强度 | 100 | 到边瞬间短促输出的强度（经 `{punish_strength}`，0=关闭） |
| 惩罚时长 (秒) | 1 | 惩罚输出持续时长，0=关闭 |
| **阈值自适应** | | |
| 刺激阶段红线自适应 | 开 | 下列红线自适应规则总开关 |
| 每次边控后红线下降 (%) | 0 | 成功边控后红线立即下降的百分比 |
| 无高潮红线缓降等待 (秒) | 100 | 刺激阶段该时长未到边，红线开始缓降 |
| 红线下降速度 (%/s) | 1.0 | 红线缓降速率 |
| 蓝线跟随下降 (%) | 30 | 红线每降 1 kPa 蓝线跟随的百分比 |
| 冷静阶段蓝线自适应 | 开 | 超时未恢复时上调蓝线 |
| 未恢复蓝线上升等待 (秒) | 100 | 冷静阶段该时长未恢复，蓝线开始上升 |
| 蓝线上升速度 (%/s) | 0.5 | 蓝线上升速率（恒不越过红线） |
| 漏气补偿 (kPa) | 0 | 叠加到读数的固定补偿（官方默认 3） |
| **映射表 / 推送链** | | |
| 输入映射表（模块 → 核心） | 空 | 行 `{param, expr}`，优先级最高；留空且无推送链时用默认行（郊狼 A/B ← max(刺激, 惩罚)） |
| 输出映射表（核心 → 模块） | 空 | 行 `{param, name, expr, type}`；留空用默认行（BMTR.Pressure → pressure、BMTR.EdgeState → edge） |
| 推送链 (events) | 空 | 行 `{name, trigger, arg, actions: [{dir: "in", param, var}]}`：变量连续推送到核心参数；无 mappings 行时生效 |
| 派生变量 (temps) | 空 | 行 `{name, expr}` 每拍求值 / `{name, value}` 静态初值，供推送链与映射表引用 |

映射表、推送链与闭环参数支持**热生效**（联动页「保存设置」即重载）。
模块不做设备管理：派发的目标设备由核心按输入路由解析（各类型首台，
跳过灵猫）。

## 常见问题

- **`app` 模式没有反应？** 需要 DG-Lab 4.0 App 的边控玩法会话在跑
  （Socket V4 连接）；蓝牙直连的灵猫没有官方边控状态，请用 `sensor` 模式。
- **多台灵猫怎么换绑？** 在联动页「输出映射表」把行改指向目标
  （如 `BMTR.2.Pressure`）。
- **气压读数偏低？** 腔体漏气时读数会偏低，调大「漏气补偿」
  （叠加到气压读数上的固定偏移，官方默认 3 kPa）。
